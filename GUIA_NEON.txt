┌────────────────────────────────────────────────────────────────────────────────┐
│ ⚠️  TROUBLESHOOTING                                                             │
└────────────────────────────────────────────────────────────────────────────────┘

PROBLEMA: "UNIQUE constraint failed"
SOLUÇÃO:
  → O usuário admin já existe
  → Execute apenas o SELECT para confirmar
  → Você pode fazer login normalmente

PROBLEMA: Login falha com "Email ou senha incorretos"
SOLUÇÃO:
  1. Volte ao Neon SQL Editor
  2. Verifique o usuário:
     SELECT email, role FROM users WHERE email = 'admin@vila-bele.com';
  3. Se não aparecer nada, execute o INSERT novamente:
     INSERT INTO users VALUES (...) [confira o setup-neon.sql]
  4. Tente fazer login novamente

PROBLEMA: Servidor responde 500 na página de login
SOLUÇÃO:
  1. Verifique o .env.local:
     DATABASE_URL=postgresql://neondb_owner:npg_...
  2. Confirme que a URL está correta
  3. Teste a conexão ao Neon manualmente (via CLI):
     psql "postgresql://neondb_owner:npg_...@ep-...neon.tech/neondb?sslmode=require"

PROBLEMA: "Failed to connect to database"
SOLUÇÃO:
  1. Verifique internet (Neon é online)
  2. Verifique DATABASE_URL em .env.local
  3. No Neon, verifique se a tabela 'users' existe:
     SELECT * FROM information_schema.tables WHERE table_name = 'users';
